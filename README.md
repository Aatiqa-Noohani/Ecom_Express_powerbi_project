## 📌 Project Overview

**Ecom Express** is a Power BI e-commerce analytics project created to transform sales data into an interactive business dashboard.

The dashboard provides a clear view of important business metrics and allows users to explore performance across:

- 🛍️ Products
- 🗂️ Categories
- 📍 States
- 📅 Year and Quarter
- 💰 Revenue
- 🧾 Sales
- 📈 Average Order Value (AOV)

The goal of this project is to demonstrate practical **data analysis, data visualization, dashboard design, and business intelligence skills using Microsoft Power BI**.

---

## 🎯 Business Objectives

This dashboard was designed to answer questions such as:

- What is the overall revenue generated?
- What are the total sales?
- What is the average order value?
- Which products contribute the most revenue?
- Which product categories perform best?
- Which states generate higher revenue?
- How does revenue change across quarters?
- How can users filter the dashboard to investigate specific categories?

## 📊 Dashboard Highlights

### 💳 KPI Cards

The dashboard includes high-level KPI cards for:

| KPI | Purpose |
|---|---|
| **AOV** | Measures average order value |
| **Sales** | Provides an overall sales metric |
| **Revenue** | Shows total revenue generated |

### 🛒 Revenue by Product

A ranked bar chart helps compare revenue generated by individual products.

### 🗂️ Revenue by Category

Category-level analysis makes it easier to compare performance across product groups such as:

- Laptop
- Mobile
- Headphones
- Tablet
- Accessory
- Charger
- Mouse
- Speaker
- Cable

### 📍 Revenue by State

The dashboard provides a geographic/state-level comparison of revenue to help identify stronger-performing markets.

### 📅 Revenue by Year and Quarter

A trend chart shows how revenue changes over time and helps identify quarterly performance patterns.

### 🔎 Interactive Category Navigation

Category buttons at the top of the dashboard make the report easier to explore and filter.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.pbix` Power BI file in **Microsoft Power BI Desktop**.
3. Refresh the dataset if required.
4. Use the category filters/buttons to interact with the dashboard.
5. Explore product, category, state, and quarterly revenue performance.
